# CBR Rates Tracker

Каждый день забирает курсы USD, EUR и CNY с [API ЦБ РФ](https://www.cbr-xml-daily.ru/), сохраняет их в SQLite, считает изменение за день и за неделю и отправляет сводку в Telegram.

```
Курсы ЦБ РФ на 08.10.2026
Изменение к 07.10.2026

USD   85.4811  ▼ 0.2305 (-0.27%)  неделя +2.30%
EUR   96.3287  ▲ 0.2974 (+0.31%)  неделя +1.53%
CNY   12.7516  ▼ 0.0468 (-0.37%)  неделя +2.23%
```

Стек: Python 3, requests, pandas, SQLite, python-dotenv, pytest.

## Установка

```bash
git clone https://github.com/VimexOff/Cbr-Rates-Tracker.git
cd Cbr-Rates-Tracker
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env
```

В `.env` указать токен бота от [@BotFather](https://t.me/BotFather) и chat id. Chat id можно узнать так: написать боту любое сообщение и открыть `https://api.telegram.org/bot<токен>/getUpdates`.

## Запуск

```bash
.venv/bin/python backfill.py       # один раз: история за 14 дней из архива ЦБ
.venv/bin/python main.py           # получить курсы, сохранить, отправить сводку
.venv/bin/python main.py --dry-run # показать сводку без отправки
```

Отдельные шаги можно запускать по одному: `fetch.py` выводит курсы в консоль, `storage.py` сохраняет их в базу, `analysis.py` считает изменения, `notify.py` отправляет сводку.

## Расписание

Linux, cron (`crontab -e`):

```
0 10,12,14 * * * cd /path/to/Cbr-Rates-Tracker && .venv/bin/python main.py --alert-after 14 >> rates.log 2>&1
```

На macOS то же самое делается через launchd: в `~/Library/LaunchAgents` кладётся plist с `StartCalendarInterval`.

Запусков несколько, чтобы сводка пришла, даже если в 10:00 сайт ЦБ или Telegram не ответил. Сводка за одну дату отправляется только один раз, остальные запуски ничего не делают.

С `--alert-after 14` запуск в 14:00 или позже при ошибке пишет о ней в тот же Telegram-чат, но только если за день не было ни одного удачного запуска. Если скрипт не запустился совсем (например, компьютер выключен) или недоступен сам Telegram, предупреждения не будет, ошибка останется в логе.

## Как устроено

- **Дубли.** В таблице `rates` первичный ключ `(date, code)`, запись идёт через `INSERT ... ON CONFLICT DO UPDATE`. Повторный запуск обновляет строки, а не добавляет новые. Отправленные сводки отмечаются в таблице `sent_summaries`.
- **Выходные и праздники.** ЦБ устанавливает курсы по рабочим дням, и действуют они со следующего дня, то есть со вторника по субботу. Субботний курс действует до понедельника, а курс перед праздниками — до их конца. В такие дни API отдаёт уже отправленный курс, поэтому бот молчит.
- **Недельное изменение.** Считается по своей базе: берётся последний курс на дату не позже, чем 7 дней назад. Чтобы история была с первого дня, `backfill.py` загружает её из архива `https://www.cbr-xml-daily.ru/archive/ГГГГ/ММ/ДД/daily_json.js`. На даты без нового курса архив отвечает 404, такие даты пропускаются.
- **Ошибки.** У запросов таймаут 10 секунд. При сетевом сбое скрипт делает 3 попытки с паузой между ними. Ошибки пишутся в stderr, при запуске по расписанию они попадают в лог. Токен бота не попадает в текст ошибок.
- **Проверка данных.** Курс должен быть положительным числом, даты корректными, а формат ответа ожидаемым, иначе запуск считается ошибкой и данные не сохраняются. Если курс за день изменился больше чем на 20%, сводка всё равно уходит, но с пометкой сверить цифру с cbr.ru.

## Тесты

```bash
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m pytest
```

Тесты проверяют подсчёт изменений за день и за неделю (включая выходные и короткую историю) и защиту от дублей в базе.
